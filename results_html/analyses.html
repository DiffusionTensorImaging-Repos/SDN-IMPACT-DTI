Analyses

Two parts: how the memory outcomes are built from the recognition task, and how each is tested against the along-tract microstructure.

1 · Calculating memory

From the feedback task, each mother gets, per condition (social faces, monetary doors), one accuracy score and two positivity-bias scores.

Accuracy: d′

d′ = z(hit rate) − z(false-alarm rate)
signal-detection accuracy; z is the inverse-normal. Higher means better discrimination of seen from unseen items.

Recomputed from raw trials as a transparency check. It matched the study's export closely (social r = 0.96, monetary r = 0.99), so this is a clean, standard recognition d′.

Positivity bias: two scores

HitRateBias
= TrueMempos/Totalpos − TrueMemneg/Totalneg
positivity skew in correct memories
FABias
= FalseMempos/Totalpos − FalseMemneg/Totalneg
positivity skew in false memories

Zero-valence rule: a term whose denominator is 0 (a mother who produced no memories of one valence) is set to 0, giving her a defined, maximally-positive score rather than dropping her. It changes only those subjects. Compliance is screened first, so it never rescues a yes-to-everything responder.

Why is social d′ lower than monetary?

d′ has two ingredients: the hit rate (memory strength) and the false-alarm rate (false positives). Splitting them shows the difference is entirely in false alarms.

Paired t-tests, n = 52.

Social and monetary items are remembered equally well; hit rates are essentially identical (0.56 vs 0.54, p = 0.40). The only difference is that the social task produces significantly more false alarms (0.527 vs 0.460, p = 0.008): mothers more often falsely remember social faces they never chose. So the lower social d′ is not weaker memory, it is more false positives.

This is the same phenomenon the tract results are about. The robust VTA→HPC effect is on social positivity bias in false memories, and here, at the behavioural level, false memories are exactly what distinguishes the social task. Memory strength is matched across domains; the social signal lives on the false-alarm side.

2 · Analyses

Six outcomes (social and monetary × d′, HitRateBias, FABias) tested against each tract's along-node microstructure, for all four metrics, plus a hippocampus-region control.

Model, per node

At each of the 100 nodes, a linear model of the outcome on that node's microstructure value plus five nuisance covariates: ICV, tract streamline count and mean length (so a result is not just a bigger or denser tract), head motion, and maternal age.

full    y ~ node + ICV + Mean_tckstats + Count_tckstats + absolute_motion + maternal_age
reduced  y ~        ICV + Mean_tckstats + Count_tckstats + absolute_motion + maternal_age

Correction: cluster-extent FWE by permutation

Neighboring significant nodes form a cluster. To keep 100 tests from inflating false positives, the null is built by Freedman-Lane permutation: take the reduced model's residuals, shuffle them, re-run all 100 nodes, 5,000 times, recording the largest chance cluster each time. An observed cluster counts only if it beats 95% of those. Run across 6 outcomes × 4 tracts × 4 metrics = 96 analyses, one core each.

Hippocampus control: region vs. connection

The same framework, but predicting memory from the mean NODDI inside the hippocampus ROI itself (hemisphere-matched, same covariates) instead of along the tract. This asks whether a memory signal is specific to the pathway or just reflects hippocampal tissue.

What the tests show

Full detail, all 96 tests, is in the Results browser. The headline:

  • Social positivity bias in false memories (FABias) is the robust effect. It is significant across FA, NDI, ODI, and FWF, in both hemispheres and both the anterior and posterior tract, strongest on the right. Higher FABias goes with lower FA, NDI, and ODI and higher FWF.
  • Social d′ tracks neurite density (NDI), on the left. The same left-NDI signal appears in the tract (p = 0.003) and in the hippocampus region itself (β = +0.089, p = 0.039). The region control says this is a neurite-density effect the circuit shares, not generic hippocampal tissue.
  • Monetary is essentially null (one isolated cluster), consistent with the within-subject control doing its job.
