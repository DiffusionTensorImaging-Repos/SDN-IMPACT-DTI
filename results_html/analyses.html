03 · Analyses

Scoring memory, and testing it against the tract

Two parts: how the memory outcomes are built from the recognition task, and how each is tested against the along-tract microstructure.

1 · Calculating memory

From the feedback task's encoding + recall, each mother gets, per condition (social faces / monetary doors): one accuracy score and two positivity-bias scores.

Accuracy — d′

d′ = z(hit rate) − z(false-alarm rate)
signal-detection accuracy; z = inverse-normal. Higher = better discrimination of seen vs. unseen items.

Recomputed from raw trials as a transparency check — matched the study's export closely (social r ≈ 0.96, monetary r ≈ 0.99), confirming a clean, standard recognition d′.

Positivity bias — two scores

HitRateBias
= TrueMempos/Totalpos − TrueMemneg/Totalneg
positivity skew in correct memories
FABias
= FalseMempos/Totalpos − FalseMemneg/Totalneg
positivity skew in false memories

Zero-valence rule: a term whose denominator is 0 (a mother who produced no memories of one valence) is set to 0, giving her a defined, maximally-positive score rather than dropping her. Affects only those subjects; compliance is screened first, so it never rescues a yes-to-everything responder.

Why monetary d′ > social d′ — it's a false-alarm story

The conditions differ in accuracy (0.22 vs 0.10), but not where you'd think. Hit rates are equal; mothers simply false-alarm more to social faces — saying "remember" to faces they never saw — which drags social d′ down. The monetary "advantage" is really social recognition being pulled down by positively-skewed false memories.

2 · Analyses

Six outcomes (social/monetary × d′, HitRateBias, FABias) tested against each tract's along-node microstructure, for all four metrics.

Model, per node

At each of the 100 nodes, a linear model of the outcome on that node's microstructure value plus five nuisance covariates — ICV, tract streamline count and mean length (so a result isn't just "bigger/denser tract"), head motion, and maternal age:

full    y ~ node + ICV + Mean_tckstats + Count_tckstats + absolute_motion + maternal_age
reduced  y ~        ICV + Mean_tckstats + Count_tckstats + absolute_motion + maternal_age

Correction — cluster-extent FWE by permutation

Neighboring significant nodes form a cluster. To keep testing 100 nodes from inflating false positives, the null is built by Freedman–Lane permutation: take the reduced model's residuals, shuffle them, re-run all 100 nodes — 5,000 times — recording the largest chance cluster each time. An observed cluster counts only if it beats 95% of those. Run across 6 outcomes × 4 tracts × 4 metrics = 96 analyses, one core each on the cluster.

Hippocampus control — region vs. connection

The same regression framework, but predicting memory from the mean NODDI inside the hippocampus ROI itself (hemisphere-matched, same covariates) instead of along the tract. This asks whether a memory signal is specific to the pathway or just reflects hippocampal tissue.
