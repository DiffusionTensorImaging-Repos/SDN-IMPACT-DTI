02 · Pipeline

From raw scans to tract microstructure

Three stages: preprocessing (standard diffusion cleanup + fiber modeling), tractography (drawing the VTA→HPC tract, then cleaning it), and microstructure (FA + NODDI profiled along each tract). Every step is a command — expand for the rationale, key output, and script.

57 subjects, run in parallel on the Temple cluster inside tmux. Full scripts + audits in the repo ReadMe (Steps 1–30).

APreprocessingstandard cleanup + fiber model · MRtrix / FSL / ANTs

Customary diffusion preprocessing — the cleanup every DTI study runs before anything interesting. Concise here; none of it is the contribution.

Clean the raw data
dcm2niixdcm2niix
Info

Convert the scanner's raw DICOM to NIfTI. Only subjects with all four required scans (T1, diffusion, AP/PA fieldmaps) were kept.

Output

57 usable subjects; 5 dropped here for missing scans (s1253, s1476, s578, s820, s999-pilot).

antsBrainExtraction.shANTs
Info

Skull-strip the T1 by warping a brain-only template onto each subject. Used the NKI adult template (appropriate for grown women). Every stripped brain eyeballed in FSLeyes.

Script
antsBrainExtraction.sh -d 3 -a "$T1" -e "$TEMPLATE" -m "$TEMPLATE_MASK" -o "$out/"
topupFSL
Info

Correct susceptibility distortion. Stack the first b=0 of the opposed AP/PA fieldmaps, then estimate the distortion field. Output feeds eddy so volumes get un-distorted in the same pass.

Script
# build the AP/PA pair, then estimate the field
fslroi ${subj}_fmapAP a2p_b0 0 1 ; fslroi ${subj}_fmapPA p2a_b0 0 1
fslmerge -t merged_b0s a2p_b0 p2a_b0
topup --imain=merged_b0s --datain=acqp.txt --config=b02b0_1.cnf \
      --out=${subj}_topup --iout=${subj}_topup_corrected_b0 --fout=${subj}_topup_fieldmap
fslmaths -Tmean · betFSL
Info

Average the corrected b=0 volumes into a clean reference, then make a brain mask from it. Downstream steps compute only inside the mask.

Script
fslmaths ${subj}_topup_corrected_b0 -Tmean ${subj}_topup_Tmean
bet ${subj}_topup_Tmean brain -m -f 0.2 -g 0.1 -R
dwidenoise · mrdegibbs · dwiextractMRtrix3
Info

Remove thermal noise (MP-PCA) and Gibbs ringing, then drop the unstable b=250 shell (Olson-lab convention). Kept shells: 0, 1000, 2000, 3250, 5000.

Script
dwidenoise -mask brain_mask dwi denoised
mrdegibbs denoised denoised_degibbs
dwiextract denoised_degibbs -fslgrad bvec bval -shells 0,1000,2000,3250,5000 dwi_no_b250 \
           -export_grad_fsl dwi_no_b250.bvec dwi_no_b250.bval
eddy --repolFSL (+ QUAD/SQUAD)
Info

The big correction: head motion, eddy-current distortion, and the TOPUP susceptibility field, all at once, with outlier-slice replacement (--repol). Three QC layers followed: eddy_quad (per-subject), eddy_squad (group), and a manual FSLeyes scroll-through.

Output

Motion low across the board — group mean absolute motion 0.27 mm; exclusion rule was >2 mm, nobody hit it. Per-subject qc_mot_abs becomes a covariate.

Script
eddy --imain=dwi_no_b250 --mask=brain_mask --acqp=acqp.txt --index=index.txt \
     --bvecs=dwi_no_b250.bvec --bvals=dwi_no_b250.bval --topup=${subj}_topup \
     --out=${subj}_eddy --repol --cnr_maps
Build the fiber model
dwiextract · dtifitMRtrix3 · FSL
Info

Fit the diffusion tensor on the low shells (b=0,1000) → FA (and MD, RD). FA is one of the four microstructure metrics carried to the analyses.

Script
dwiextract data -fslgrad bvecs bvals -shells 0,1000 data_1000 -export_grad_fsl ...
dtifit -k data_1000 -o DTI -m brain_mask -r bvecs_1000 -b bvals_1000
fslmaths DTI_L2 -add DTI_L3 -div 2 DTI_RD
flirt · convert_xfmFSL
Info

Build the linear transforms between diffusion, T1, and MNI space, and invert the set. The one reused later is str2diff (T1→diffusion), to bring the ROIs into the DWI grid.

Script
flirt -in b0_brain -ref t1_brain -omat diff2str.mat -dof 6          # rigid
flirt -in t1_brain -ref MNI152_T1_2mm_brain -omat str2standard.mat -dof 12  # affine
convert_xfm -omat str2diff.mat -inverse diff2str.mat
Atropos · fslstats -VANTs · FSL
Info

Estimate intracranial volume: segment the T1 into CSF/GM/WM and sum. ICV is a covariate so a finding isn't just "bigger heads."

Script
Atropos -d 3 -a brain -x mask -i KMeans[3] -o [seg.nii.gz,prob%02d.nii.gz]
fslstats prob01 -V   # sum CSF+GM+WM = ICV
mrconvert · dwi2response (dhollander)MRtrix3
Info

Repackage into MRtrix .mif (gradients in the header), then estimate the single-fiber / GM / CSF response functions from each subject's own data (Dhollander, no atlas).

Script
mrconvert data.nii.gz -fslgrad bvecs bvals dwi.mif
dwi2response dhollander dwi.mif wm_response.txt gm_response.txt csf_response.txt -mask mask.mif
responsemeanMRtrix3
Info

Average every subject's three response functions into one shared group set — so later differences reflect biology, not per-subject response noise.

Script
responsemean */wm_response.txt group_wm_response.txt   # and gm, csf
dwi2fod msmt_csd · mtnormaliseMRtrix3
Info

The core fiber model. MSMT-CSD (multi-shell multi-tissue constrained spherical deconvolution) turns each voxel's signal into an FOD; mtnormalise rescales them to be comparable across tissue and across people. The normalized WM FOD is the input to tractography.

Script
dwi2fod -mask mask.mif msmt_csd dwi.mif \
        group_wm_response.txt wm_fod.mif group_gm_response.txt gm_fod.mif \
        group_csf_response.txt csf_fod.mif
mtnormalise wm_fod.mif wm_fod_norm.mif gm_fod.mif gm_fod_norm.mif \
        csf_fod.mif csf_fod_norm.mif -mask mask.mif
BTractographydraw the VTA→HPC tract, then clean it · MRtrix3 / ANTs / pyAFQ

The hands-on core. Grow streamlines from the VTA to the hippocampus in each hemisphere, constrained to an anatomically plausible corridor, then prune outliers.

The three ROI inputs (from Ranesh Mopuru, Olson lab; all MNI space). Seed = VTA, Pauli atlas @ 25%. Target = hippocampus, Harvard–Oxford @ 50%. Tract atlas = his VTA→HPC group mean (GroupMean_thr50), built from ~170 HCP 7T subjects — used to build the exclusion corridor below.
Fiber drawing
antsRegistrationSyNQuick.shANTs (SyN)
Info

ROIs live in MNI; tracking happens in each subject's diffusion space. First a nonlinear (SyN) warp MNI→T1 — needed because our T1s aren't already diffusion-aligned, unlike the HCP data the atlas came from.

Script
antsRegistrationSyNQuick.sh -d 3 -f ${subj}_T1_brain -m MNI152_T1_1mm_brain -o reg/mni2t1_
antsApplyTransforms · flirtANTs · FSL
Info

Push all six ROIs (VTA, HPC, tract atlas × L/R) MNI→T1→diffusion, chaining the SyN warp then the str2diff matrix. Nearest-neighbor interpolation (binary masks), re-binarized after. Visually QC'd on the diffusion image.

Script
antsApplyTransforms -d 3 -i roi_mni -r t1_brain -o roi_t1 \
    -t mni2t1_1Warp.nii.gz -t mni2t1_0GenericAffine.mat -n NearestNeighbor
flirt -in roi_t1 -ref diff_ref -applyxfm -init str2diff.mat -out roi_diff -interp nearestneighbour
fslmaths roi_diff -thr 0.5 -bin roi_diff
fslmaths — exclusion maskFSL
Info

Ranesh's original pipeline used 13 separate anatomical exclusion ROIs. His approved shortcut: take the group tract atlas, dilate 2 voxels into a corridor, add VTA + HPC, invert → one exclusion mask per hemisphere (allowed = corridor, excluded = everything else). This single mask is what lets us drop the FOD cutoff so low (next step).

Output

57/57 pass all 7 audit checks. Inclusion corridor ≈ 1,526–1,934 voxels (mean ~1,720) — a narrow, consistent VTA→HPC corridor. VTA and HPC fully contained.

Script
# per hemisphere (left shown; right identical with r_ inputs)
fslmaths left_tract_atlas_diff -dilM -dilM l_atlas_dilated        # widen corridor 2 voxels
fslmaths l_atlas_dilated -add left_VTA_diff -add left_HPC_diff -bin l_inclusion_zone
fslmaths l_inclusion_zone -binv exclusion_mask_l                  # invert: outside = excluded
tckgen — FOD-cutoff test (5 subjects)MRtrix3
Info

The one tuned parameter: the FOD amplitude cutoff (when tracking stops). Ranesh used 0.06 at 7T; 3T is noisier, so we tested 0.1 / 0.08 / 0.06 / 0.01 on 5 pilot subjects × both hemispheres. Because the exclusion corridor already constrains tracking, the usual downside of a low cutoff (spurious fibers) doesn't apply — so we could go lower than expected.

Output — streamlines hit (target 1000)
cutoffruns hitting 1000note
0.12 / 10too strict for 3T
0.08~5 / 10inconsistent (s606 L = 309)
0.0610 / 10reliable
0.0110 / 10reliable + ~5× more seed-efficient

Paths virtually identical to 0.06 (same VTA→HPC arc; length ~44 vs ~47 mm). 0.01 gives a slightly thicker TDI — which cleaning tightens below the 0.06 bundle anyway. Chose 0.01; Ranesh confirmed it's robust with the atlas mask.

Script
# looped over cutoff ∈ {0.1, 0.08, 0.06, 0.01}, both hemispheres, 5 subjects
tckgen wm_fod_norm.mif l_vta_l_hipp_${cutoff}.tck \
    -seed_image left_VTA_diff.nii.gz -seed_unidirectional \
    -include  left_HPC_diff.nii.gz \
    -exclude  exclusion_mask_l.nii.gz \
    -select 1000 -seeds 5000000 -cutoff $cutoff \
    -minlength 35 -maxlength 65 -stop -nthreads 8
tckgen — full run (all 57)MRtrix3
Info

Same command at production budget: 2,500 streamlines from up to 25M seed attempts, cutoff 0.01. Later added an anterior VTA→HPC tract with a second atlas Ranesh provided — identical pipeline — giving 4 tracts: posterior L/R and anterior L/R.

Output

All 114 posterior tracts (57 × 2) reached the full 2,500 streamlines; all 114 anterior masks/tracts passed QC. Four tracts per subject.

Script
tckgen wm_fod_norm.mif l_vta_l_hipp_0.01.tck \
    -seed_image left_VTA_diff -seed_unidirectional -include left_HPC_diff \
    -exclude exclusion_mask_l -select 2500 -seeds 25000000 \
    -cutoff 0.01 -minlength 35 -maxlength 65 -stop
Cleaning
clean_bundle (Mahalanobis)pyAFQ
Info

Prune anatomically weird streamlines by Mahalanobis distance — anything >3 SD from the bundle's core shape, or >2 SD off in length, dropped over 5 rounds. Ported from Ranesh's cleaning script.

Output

Retention ~30–45% of streamlines; the rest trimmed as outliers. Cleaned bundles are tighter than the conservative-0.06 version — confirming the low cutoff cost nothing.

Script
sft = load_tractogram(in_tck, ref_img, bbox_valid_check=False)
cleaned_sft, idx = clean_bundle(
    sft, n_points=100, clean_rounds=5,
    distance_threshold=3,   # 3 SD Mahalanobis
    length_threshold=2,     # 2 SD from mean length
    stat='mean', return_idx=True)
tckmap — visual QCMRtrix3
Info

For every cleaned tract, a TDI (track-density heatmap) overlaid on the b=0 to eyeball the shape; auto-flags catch anything too sparse or too diffuse.

Output

All tracts passed and show the expected VTA→hippocampus arc. See the Results browser for per-subject renders.

Script
tckmap cleaned.tck tdi.nii.gz -template left_VTA_diff.nii.gz
CMicrostructureFA + NODDI along each tract · dipy / AMICO

Measure the tissue along each tract — not one number per tract, but a 100-point profile from the VTA end to the hippocampus end. Four metrics: FA (tensor) + NDI, ODI, FWF (NODDI).

afq_profile — FAdipy
Info

Sample FA at 100 nodes evenly spaced along the tract. Every streamline is oriented the same way (so node 1 is always the same end), resampled to 100 points, and Gaussian-weighted (core streamlines count more). Analyses use the middle nodes (~25–75); the ends are dropped for partial-volume contamination. Ported from Ranesh's nodewise_noddi.py.

Script
oriented = orient_by_streamline(streamlines, quickbundles_centroid)
fa = afq_profile(FA_map, oriented, affine, nb_points=100,
                 weights=gaussian_weights(oriented))
NODDI fit (modulated maps)AMICO
Info

Fit NODDI on all shells, giving three interpretable maps per voxel: NDI (neurite density), ODI (orientation dispersion), FWF (free-water fraction). Saved the modulated NDI/ODI (partial-volume-corrected, per Parker 2021) — the version Ranesh used.

Script
amico.util.fsl2scheme(bvals, bvecs, bStep=200)
# NODDI fit: b0_thr=100, doSaveModulatedMaps=True
# → fit_NDI_modulated, fit_ODI_modulated, fit_FWF
afq_profile — NDI · ODI · FWFdipy
Info

The FA-profiling step again, on the three NODDI maps. This produces the main microstructure measurements the statistics use: per subject, per tract, per metric — a 100-node profile.

Output

16 tidy tables (4 tracts × 4 metrics); each row a subject, 100 node columns. These feed the analyses.

Script

fslstats -k HPC -MFSL
Info

One extra measurement for a control analysis: the mean NODDI inside the hippocampus ROI itself (the region, not the pathway). Same Harvard–Oxford hippocampus, warped to diffusion space. Lets us ask whether memory tracks the tract specifically or just hippocampal tissue in general.
